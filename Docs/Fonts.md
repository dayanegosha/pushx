# шрифт

В pushx используется Geologica с латиницей и кириллицей. Китайские символы отображаются системным шрифтом iOS.

Geologica распространяется по SIL Open Font License 1.1. Лицензия разрешает бесплатное коммерческое использование и включение шрифта в приложение. Оригинальный variable-файл не изменён; copyright и текст лицензии сохранены в `iOS/Forma/Resources/Fonts/Geologica-OFL.txt` и включаются в bundle. Используются прямые начертания с мягкими окончаниями (`SHRP = 0`, `CRSV = 0`, `slnt = 0`) и весами 100–900. Имена PostScript для встроенных именованных начертаний начинаются с `Geologica-Thin_`.

Исходники и лицензия: [Geologica](https://github.com/googlefonts/geologica), [файл Google Fonts](https://github.com/google/fonts/tree/main/ofl/geologica), [OFL](https://github.com/google/fonts/blob/main/ofl/geologica/OFL.txt), [правила распространения OFL](https://openfontlicense.org/ofl-faq/).
