# .forma

Отжимания, которые считает iPhone.

Нативное приложение на SwiftUI с обработкой фронтальной камеры на устройстве. Монохромный интерфейс, светлая и тёмная темы, русский, английский и китайский языки.

## разработка

Проект разрабатывается для iOS 17+. Нужны Xcode и XcodeGen.

```sh
cd iOS
xcodegen generate
open Forma.xcodeproj
```

Подсчёт, история тренировок, Apple Health, вход с Apple, подписка и соревнования с друзьями добавляются отдельными этапами.
