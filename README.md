# .pushx

приложение для отжиманий на iPhone и iPad. считает движение через ARKit, показывает результат крупными цифрами и при желании озвучивает счёт. превью камеры и записи видео нет.

SwiftUI, монохромный интерфейс с настраиваемым акцентом, светлая и тёмная темы, русский, английский и китайский языки. на iPhone — только портрет, iPad поддерживает поворот. счётчик, история, Apple Health и соревнования с друзьями бесплатны. серия продолжается от 5 отжиманий в день; тихое ежедневное напоминание включается по желанию. pushx plus добавляет расширенную статистику и экспорт CSV.

## запуск

нужны macOS, Xcode и XcodeGen. минимальная версия приложения — iOS / iPadOS 17.

```sh
brew install xcodegen
cd iOS
xcodegen generate
open pushx.xcodeproj
```

выберите схему `pushx` и iPhone или iPad. при первом запуске обязателен вход с Apple; затем используется сохранённая сессия. подписка для основных функций не нужна. для автоматического подсчёта нужно физическое устройство.

## разработка

нужны собственные Apple Developer и Supabase. сервер ещё не развёрнут: без его настройки release остаётся на экране входа. покупка отключена до указания публичной политики конфиденциальности. локальный просмотр интерфейса доступен только в debug с `PUSHX_LOCAL_PREVIEW=1`; release игнорирует этот флаг.
