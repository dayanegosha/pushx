# .upra

Приложение для отжиманий на iPhone и iPad. Считает повторения через фронтальную камеру, показывает результат крупными цифрами и при желании озвучивает счёт.

SwiftUI, монохромный интерфейс с настраиваемым акцентом, светлая и тёмная темы, русский, английский и китайский языки. Счётчик, история, Apple Health и соревнования с друзьями бесплатны. UPRA Plus добавляет расширенную статистику и экспорт CSV.

## запуск

Нужны macOS, Xcode и XcodeGen. Минимальная версия приложения — iOS / iPadOS 17.

```sh
brew install xcodegen
cd iOS
xcodegen generate
open Forma.xcodeproj
```

Выберите схему `Forma` и iPhone или iPad. При первом запуске обязателен вход с Apple; затем используется сохранённая сессия. Подписка для основных функций не нужна. Для автоматического подсчёта нужно физическое устройство.

## разработка

Нужны собственные Apple Developer и Supabase. Сервер ещё не развёрнут: без его настройки Release остаётся на экране входа. Покупка отключена до указания публичной политики конфиденциальности. Локальный просмотр интерфейса доступен только в Debug с `UPRA_LOCAL_PREVIEW=1`; Release игнорирует этот флаг.
